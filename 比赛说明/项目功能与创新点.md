# 灵枢 · 项目功能与创新点

## 一、项目定位

基于大语言模型的**多工具自主调度智能体平台**——用户说一句话，智能体自己规划、自己调工具、自己交付结果。

本项目面向"让大语言模型真正能干活"的目标，设计并实现一个多工具自主调度的 AI 智能体平台。用户以自然语言提出需求后，智能体基于状态图引擎自主完成意图理解、任务规划、工具调用与结果校验，可调度文件检索、文档解析、代码沙盒、图表生成、文档产出、图片识别与生成等能力，完成资料整理、数据分析、图表绘制、报告与演示文稿生成等任务；平台配套对话式交互界面、知识库、长期记忆与系统管理后台，并通过权限隔离、沙盒执行与输入安全检测保障运行安全。

---

## 二、技术方案

| 层 | 技术选型 |
|---|---|
| 前端 | React 18 + TypeScript + Vite 6 + Ant Design 5 + Zustand + ECharts 6 |
| 后端 | Python 3.12 + FastAPI + LangGraph（智能体编排）+ SQLAlchemy(async) + asyncpg |
| 数据与缓存 | PostgreSQL 16 + Redis 7 |
| 大模型 | DeepSeek（文本推理，支持思考模式）+ 智谱 GLM（视觉理解 / 图像生成） |
| 代码执行隔离 | bubblewrap（内核级沙盒） |
| 部署 | Nginx + systemd |
| 质量保障 | 断言套件（后端）+ Playwright 端到端（前端）+ Locust 并发压测 |

**技术规模**：22 个注册工具（其中 15 项进入用户功能栏，7 项为引擎内部工具）、12 种图表类型、6 栏模型配置、5 种文档输出格式（docx / pptx / xlsx / pdf / html）。

## 三、基本功能

### 基本功能 1：账号登录与数据隔离模块
实现账号登录与角色权限控制（普通用户 / 管理员），登录采用 JWT + httpOnly Cookie 鉴权，密码经 bcrypt 加盐哈希存储；实现验证码与 IP 黑名单防暴力破解、账号禁用即时生效；不同用户的会话记录、上传文件与产出目录相互隔离，服务端对所有文件访问做组件级路径白名单校验。

### 基本功能 2：对话式交互与流式渲染模块
用户以自然语言提问，后端通过 SSE 将模型思考与工具执行过程逐字流式推送；前端实现 Markdown 渲染、多轮上下文追问、会话列表管理，以及产出物预览区（图表交互式渲染、按对话轮次切换查看、下载导出）；支持上传 xlsx / docx / pdf / pptx / 图片等文件作为对话上下文，大文件采用分片上传。

### 基本功能 3：Agent 自主编排与模型调度模块
基于 LangGraph 构建状态图式智能体引擎，把输入检查、任务规划、计划确认、能力路由、模型推理、工具执行、结果校验拆分为独立节点并按条件边流转；以"工具调用是否产生有效信息增量"作为动态收敛判据，并配置多档阶梯式护栏；关键操作先展示执行计划、经用户确认后再执行，支持执行中主动提问与异常中断恢复。

引擎内置模型分层调度：**六栏**独立配置（对话 / 辅助任务 / 定制化工具 / 视觉 / 图像生成 / 视频生成，各含平台、模型、思考强度），辅助任务按具体类型（检索精排、文档摘要、记忆提取、历史压缩等）分流并可回退默认档，候选模型目录由服务端统一下发，前端不硬编码任何模型信息。

### 基本功能 4：技能与工具调度模块
采用 Skill（文本层，描述智能体能做什么、何时触发）/ Tool（代码层，实际执行的函数）分层架构，22 个工具统一注册管理（含参数 Schema、并发队列、中文展示名等元数据）；用户可在功能栏勾选启用技能，或开启"自动选择"由模型自主决策；复杂任务可派发给子代理并行执行并汇总结果。

### 基本功能 5：知识检索与上下文管理模块
统一检索工具在知识库与用户上传文件中按关键词定位候选，再经多格式解析器读取原件（xlsx / docx / pdf / pptx）；文档按标题与段落切块（块长 500–1000 字、块间重叠 50 字）入库，检索时先做关键词扩展与权重预筛，再由辅助模型精排取前若干块。知识库按"全局 / 团队 / 个人"三态分级，检索与读取均限定在用户可见范围内。

同时实现长期记忆：对话结束后异步提取用户偏好与常用术语作为候选记忆，满足"出现频次 + 跨会话一致性"双阈值后激活，在后续对话中自动注入上下文；用户可查看、修改或清除自己的记忆。

### 基本功能 6：沙盒代码执行模块
为智能体提供安全的代码执行环境：基于 bubblewrap 构建隔离沙箱（系统目录只读、仅本次会话工作目录可写、目录级白名单挂载），并施加内存（768 MB）、CPU、进程数、单文件大小（512 MB）四项资源限额与超时强杀；智能体可自主编写并运行 Python 脚本完成数据清洗、统计汇总与复杂计算，产出文件可被后续工具继续引用。

### 基本功能 7：多模态成果产出模块
智能体按任务类型产出多种形式的交付物：

**图表**——根据数据形状选择 12 种 ECharts 图表类型（柱状图、折线图、饼图、雷达图、散点图、热力图、漏斗图、仪表盘等），输出可交互渲染的图表配置，并同步导出 PNG；
**文档**——docx 报告、PPTX 演示文稿、XLSX 表格、HTML 网页报告与 PDF 转换，图表自动以图片形式嵌入；
**图像**——按文字描述调用图像生成模型产出图片。

所有产出在预览区按对话轮次展示，支持在线预览与下载导出。

### 基本功能 8：外部工具（MCP）接入模块
遵循 MCP（Model Context Protocol）协议接入外部工具服务，实现工具注册、启停与调用转发的统一管理；外部工具需经管理员启用与用户个人启用双重校验后方可调用，调用过程全程记录审计日志，可在不修改主程序的前提下扩展平台能力。

### 基本功能 9：安全防护与管理后台模块
输入侧实现提示词注入与越狱检测（指令操控、敏感信息索取、角色越权、跨团队访问、破坏性操作、编码混淆、结构标签注入等 8 类规则）；工具侧实现路径越狱防护（路径解析 + 组件级白名单）、外部请求 SSRF 防护与产出物接口鉴权（JWT + 会话归属校验）。

管理后台提供系统概览、用户管理、团队管理、工具权限配置、模型配置、知识库管理、记忆库管理、反馈处理与日志审计，敏感操作留痕可追溯。

### 基本功能 10：媒体理解与转写模块
音频 / 视频上传后由本地部署的语音识别模型转写为带时间戳的文字稿（本地推理，不依赖外部 API、无调用成本），并支持说话人分离；视频任务在此基础上叠加画面理解，输出综合的内容分析。会议纪要工具把"录音 → 转写 → 按场景总结 → 归档导出"串成一条完整链路。

## 四、创新功能

1. **基于状态图的智能体编排与动态收敛机制**：将输入过滤、任务规划、计划确认、能力路由、模型推理、工具执行、结果校验抽象为图节点与条件边，运行期以"工具调用的信息增量"（而非固定步数）作为进展判据，并配置多档阶梯式护栏（连续无进展、连续无交付、同参数重复、单轮失败熔断），在长任务完成率与失控防护之间取得平衡。

2. **Skill / Tool 双层能力模型与多级权限闸门**：能力描述（注入提示词的自然语言契约）与执行函数（代码层实现）解耦；工具可见性依次经过"用户勾选集合 → 系统内部工具恒注入 → 团队黑名单 ∩ 用户黑名单 → 外部工具双闸门"四道过滤，实现同一套引擎的运行期能力面裁剪。

3. **内核级沙盒与多维操作空间隔离**：以 bubblewrap 构建文件系统命名空间隔离（系统根只读、按白名单挂载可写工作域、默认断网），并从数据范围、工具白名单、文件目录、网络开关、资源限额五个维度约束智能体行为，形成"提示词—工具—系统调用"三层递进的越权防护。

4. **共识驱动的长期记忆流水线**：对话结束异步提取候选记忆，以"出现频次 + 跨会话一致性"双阈值判定激活，超期未达标自动淘汰；记忆按用户隔离存储并支持人工干预，实现无监督沉淀与偏好污染抑制。

5. **模型分层路由与平台无关适配层**：六栏解耦配置，辅助任务与定制化工具按任务类型分流并可回退默认档；以 OpenAI 兼容协议统一多平台调用入口，配合运行期平台覆盖机制，实现"一次配置、按任务选模"的成本与效果平衡。

6. **子代理并行执行体与事件流回放**：主智能体将复杂子任务派发给隔离子代理（独立上下文、独立写域、独立事件通道、独立轮次预算），事件经队列透传聚合；长任务后台化执行，前端断线后按事件序号回放恢复进度，任务状态以数据库为准。

7. **MCP 协议化的外部工具治理**：以协议标准接入外部服务，采用"管理员启用 ∧ 用户启用"双闸门与子工具挂接机制，实现零改造扩展能力与全量调用审计；配套真机浏览器驱动，让智能体能在真实浏览器中完成网页任务。

8. **并发治理与稳定性工程**：按资源类型划分 10 个调用队列并设置并发上限与超时兜底，长耗时任务互斥串行；配合结构化日志、操作审计、外部连通性探针与发布自检，形成完整的可观测、可运维体系。
